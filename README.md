# LibKat

Нативный клиент MangaLib / HentaiLib / SlashLib / AnimeLib для старых Android, начиная с **4.4 KitKat**.
Сделан для Samsung Galaxy Tab 3 7.0 (SM-T211): там сайт не открывается, а Mihon не ставится.

## Что умеет

- Каталог с поиском и сортировками (популярное, рейтинг, просмотры, новинки, обновлённые).
  На обложках значок папки закладок в её цвете; качество обложек выбирается в настройках.
- Закладки аккаунта: все папки, включая свои и списки AnimeLib. Статус тайтла меняется из его карточки.
- Читалка в двух режимах:
  - лента для манхвы и вебтунов, длинные страницы режутся на тайлы, чтобы хватало памяти;
  - по страницам слева направо или справа налево, с зумом щипком и двойным тапом;
  - в режиме «авто» манхва открывается лентой, манга — справа налево; режим можно сменить
    из меню, он запоминается для каждого тайтла;
  - листать можно тапами по краям, свайпами и клавишами громкости, тап по центру показывает меню;
  - для каждой главы запоминается место, на котором остановились.
- Выбор перевода, если у главы их несколько.
- Комментарии к тайтлу, главе и серии (пока только чтение).
- Аниме из плеера AnimeLib (mp4 360p–2160p):
  - смотреть во встроенном плеере или во внешнем (VLC, с субтитрами);
  - позиция просмотра запоминается.
- Вход по логину и паролю без WebView. Аккаунт один на все сайты *LIB.
- SOCKS5-прокси, с логином или без:
  - режим «только API и вход» — картинки и видео идут напрямую;
  - режим «весь трафик»;
  - DNS-запросы резолвит сам прокси.

Kodik пока не поддерживается, видео идёт только из собственного плеера AnimeLib, а он отдаёт ссылки только после входа.

## Как это устроено

| Проблема на 4.4 | Решение |
|---|---|
| Нет TLS 1.3 и современных шифров | [Conscrypt](https://github.com/google/conscrypt) 2.5.3 (minSdk 9) |
| Нет корневых сертификатов вроде ISRG Root X1 | Свой бандл Mozilla (`assets/cacert.pem`) плюс системное хранилище |
| OkHttp 4+ не поддерживает 4.4 | OkHttp 3.12.13 |
| В `java.net` на Android есть только SOCKS4 | Своё рукопожатие SOCKS5 (`core/Socks5SocketFactory`) |
| Вход на сайте через WebView и JS-капчу | OAuth (authorization code + PKCE), как у сайта; капча ALTCHA решается перебором SHA-256 |
| Системный плеер не справляется с HTTPS | Локальный прокси `http://127.0.0.1` (`StreamProxy`) с поддержкой Range |

API тот же, что у сайта: `https://api.cdnlibs.org/api/...`. Обязательно передавать заголовки `Site-Id` (1 — Manga, 2 — Slash, 4 — Hentai, 5 — Anime) и `Referer`, иначе DDoS-Guard отвечает 403.

## Сборка

Нужны JDK 17+ и Android SDK (platform 34, build-tools 34):

```sh
echo "sdk.dir=/путь/к/android-sdk" > local.properties
./gradlew assembleDebug        # app/build/outputs/apk/debug/app-debug.apk
```

APK подписывается общим ключом `app/libkat.keystore` (пароль `libkat`). Поэтому новую версию можно ставить поверх старой, где бы её ни собрали.

## Тесты

Сетевое ядро (`core/`) написано на чистой Java, поэтому его можно проверить на JVM против настоящего API:

```sh
./gradlew testDebugUnitTest                         # только офлайн-тесты
./gradlew testDebugUnitTest -Dlive=true             # плюс живой API и SOCKS5
LIB_LOGIN=... LIB_PASSWORD=... ./gradlew testDebugUnitTest -Dlive=true   # плюс вход
```
